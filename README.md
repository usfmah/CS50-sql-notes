# CS50's Introduction to Databases with SQL — Notes

Personal notes and problem set solutions for [CS50's Introduction to Databases with SQL](https://cs50.harvard.edu/sql/).

## Purpose

Track progress through the 7-week course: structured notes from each lecture plus solutions to the weekly problem sets and final project.

## Structure

```
.
├── week0/  # Querying — SELECT, WHERE, LIKE, ORDER BY, aggregates (SQLite)
├── week1/  # Relating — JOINs, foreign keys, relating tables
├── week2/  # Designing — Normalization, ER diagrams, schema design
├── week3/  # Writing — INSERT, UPDATE, DELETE, transactions
├── week4/  # Viewing — Views, CTEs, subqueries
├── week5/  # Optimizing — Indexes, EXPLAIN, query optimization
├── week6/  # Scaling — MySQL, PostgreSQL, scaling concepts
├── project/ # Final project
└── weekN/
    ├── notes/        # Lecture notes (notes.md)
    └── problem_set/  # Problem set solutions
```

Each `weekN` corresponds to one course week. `notes/` contains distilled lecture notes; `problem_set/` contains my solutions.

## Usage

Browse notes directly in `weekN/notes/notes.md`. Problem sets are self-contained per week — see each `problem_set/` for SQL files and datasets.
